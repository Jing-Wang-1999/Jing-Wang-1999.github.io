# Jing Wang's academic homepage

This repository contains the GitHub Pages source for Jing Wang's academic profile. It uses a custom Jekyll layout and stylesheet, with no theme plugin or client-side JavaScript.

## Update the site

- `_data/publications.yml` is the single source for the publication list. Set `first_author` or `co_authored`, then add the title, authors, venue, year, and optional paper link or contribution note.
- `index.md` contains the introduction, education, and both publication lists.
- `_layouts/default.html`, `_includes/publication-row.html`, and `assets/css/style.css` define the shared layout.
- `other-publications.md` preserves the old URL and points readers to the main publication list.
- `profile.jpg` is a small portrait; keep its natural aspect ratio or replace it with a higher-resolution image.

Check publication details against the [HKUST group publication list](https://zhiyaoxie.com/publications/). Display the name as **Jing Wang (王京)**. Sebastian may appear in the introduction. GitHub Pages renders the Markdown files after changes are pushed to its publishing branch.
